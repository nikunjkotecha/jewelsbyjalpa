# Jewels by Jalpa

A responsive, one-page jewellery website for jewelsbyjalpa.com.

## Run locally

Open `index.html`, or serve this directory with `python -m http.server 8000`.

## Deploy

Upload `index.html`, the `assets/` directory and favicon files to the web root. No build step or dependencies are required.

The page includes Instagram and WhatsApp enquiry links and uses artwork supplied by the brand. Icon files include SVG, ICO and an Apple touch icon.
